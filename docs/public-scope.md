# Public Case Study Scope

This repository documents engineering concepts behind Koowky.

## Included

- high-level system architecture
- generalized agent/tool patterns
- multi-tenant design principles
- workflow architecture
- reliability considerations
- sanitized pseudocode and diagrams

## Not included

- production source code
- customer or tenant information
- API keys / credentials
- private prompts
- proprietary automation workflows
- internal provider configuration
- confidential commercial logic

All examples are generalized and intended to explain engineering decisions rather than reproduce the production implementation.
